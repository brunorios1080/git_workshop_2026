# Demo: Meet the Class · 10 minutes

**Open:** https://github.com/brunorios1080/git_workshop_2026

1. **Fork** the repo → open your fork in **Codespaces**.
2. Follow the README to create a **branch** and your profile in `students/`.
3. Add your **name, major, three hobbies, and favorite snack**.
4. Run **git add → git commit → git push** using the README commands.
5. Open a **pull request to the class repo**, then comment on a classmate's PR.

**Watch your instructor merge contributions into one class directory!**

Setup tip: Sign in and start Codespaces before the activity begins.
