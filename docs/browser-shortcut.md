# Browser shortcut

Use this if Codespaces isn't available. You can still practice making a commit, opening a PR, and collaborating. Browser edits create commits on GitHub directly; this route doesn't practice the terminal push command.

1. **Fork** the class repo into your own GitHub account.
2. In your fork, use the branch selector (initially `main`) to create a branch named `profile/YOUR-USERNAME`.
3. On that branch, choose **Add file → Create new file**. Name it `students/YOUR-USERNAME.md`.
4. Paste the short template below, fill it in, and click **Commit changes**. Commit to your profile branch.
5. Choose **Contribute → Open pull request**. Check that the base is `brunorios1080/git_workshop_2026` / `main` and the head is your fork's profile branch, then create the PR.
6. Read a classmate's PR in the class repo and leave a friendly comment.

```markdown
# Hi, I'm YOUR NAME!

- Major or interest:
- Three hobbies:
- Favorite snack:
```
