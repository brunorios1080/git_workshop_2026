# Run the activity in 10 minutes

**Outcome:** Each student pushes a profile, opens a PR to the class repo, and comments on a classmate's contribution. You merge a few examples live.

## Before the timer

- Share the class repo: https://github.com/brunorios1080/git_workshop_2026
- Have students sign in, fork it, and start a Codespace early if possible. Codespaces startup and account setup can exceed the activity time.
- Students work in their own forks, so a public repo needs no collaborator invitations for this activity.
- Pair neighbors for the comment step. Nicknames and brief answers are welcome.
- If Codespaces isn't available to someone, use the [browser shortcut](browser-shortcut.md).

## On the clock

| Minutes | Students do | You do |
| --- | --- | --- |
| 0–2 | Fork and open Codespaces, if not already ready. | Show the repo and example profile. |
| 2–5 | Create a branch and fill in one profile. | Point out each student's unique filename. |
| 5–7 | Add, commit, and push. | Explain that the push went to their fork. |
| 7–9 | Open a PR to the class repo. | Show the base repo and compare branch. |
| 9–10 | Comment on a classmate's PR. | Merge a few PRs and refresh the students folder. |

An open PR and a classmate comment count as completion; merging every student's PR can happen afterward.

## Fit with your slides

This replaces the current “Demo part,” where students create separate personal repos and major/hobbies files. Students still use Codespaces and run add, commit, and push. One profile per student keeps the edits quick; forks and PRs bring their work into a shared class repo.

Use the [slide-ready text](demo-slide.md) for a short activity slide.

## Closing prompt

“Your commit saved a snapshot. Your push put it on GitHub. Your pull request let us review it and bring it into the class project.”

If there is extra time, show how to pull the merged class work in your own local clone. Leave conflict resolution and a second editing round for another session.

References: GitHub's [Codespaces quickstart](https://docs.github.com/en/codespaces/quickstart) and [pull request introduction](https://docs.github.com/en/pull-requests/get-started/about-pull-requests).
